How V1 and V2 work, and their limits

V1 · raw history

  • Every overlapping N-day window of Bybit BTCUSD daily bars since late 2018, where N is the days to expiry.
  • Each window's close-to-close return is applied to today's spot. The share of windows ending above a strike is the probability.
  • Touch uses each window's highest high and lowest low.
  • Equal weights, historical drift kept. BTC's huge past rally pushes calls up and puts down.

V2 · adjusted

  • Lookback limits history to recent years; recency weight fades old windows with the chosen half-life.
  • Volatility scaling: each window is rescaled by (vol expected now over N days) ÷ (vol expected then over N days), using EWMA vol (λ=0.94) mean-reverting with a 30-day half-life. It keeps history's shape (fat tails, skew) but matches today's regime. "Market ATM IV" scales to the option market's own vol, isolating shape differences.
  • Zero drift centres outcomes on the expiry's forward, the same anchor option prices use. Historical drift centres on spot and keeps the trend.

Read it carefully

  • Overlapping windows are not independent. A 90-day expiry has only ~30 truly separate periods since 2018 (shown under each vol tile).
  • Market prices include information history lacks: events, positioning, funding. A gap is a question, not a trade.
  • A high win rate is not profit. Short far-OTM options win often and lose big. Compare fair value with price, not just probability.
  • Bybit option fees and slippage are not included. Small edges disappear.
